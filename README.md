# 🏦 Sistema Bancário em Python

Sistema bancário simples desenvolvido em Python, com foco em lógica de programação, funções e organização de código. O projeto simula operações básicas de um banco, como depósitos, saques e extrato, com regras de negócio reais.

---

## 🚀 Funcionalidades

* Depósito de valores
* Saque com regras de limite
* Extrato de movimentações
* Limite diário de saques
* Validações de saldo e valores

---

## 🧠 Conceitos aplicados

* Funções em Python
* Estruturas condicionais (`if/elif/else`)
* Loops (`while`)
* Manipulação de strings (extrato)
* Controle de estado (saldo, saques)
* Boas práticas de organização de código
* Uso de biblioteca externa (colorama)

---

## 📦 Tecnologias utilizadas

* Python 3
* Colorama
* Streamlit

---

## 🖥️ Como funciona

O sistema funciona via terminal e apresenta um menu interativo:

```
[1] Depositar
[2] Sacar
[3] Extrato
[4] Sair
```

---

## 📊 Exemplo de uso

```
Depósito: R$ 100.00
Saque: R$ 50.00
Saldo atual: R$ 50.00
```
